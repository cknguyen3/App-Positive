Get it on all your devices

  • iPhone / iPad (app): in Safari tap Share → Add to Home Screen.
  • iPhone / iPad (widget): install the free Scriptable app, add the Daily Sunshine script (open it, Select All → Copy, then paste into a new Scriptable script), then add a Scriptable widget to your home screen and pick the script.
  • Android (app): in Chrome tap ⋮ → Install app.
  • Android (widget): install the Daily Sunshine APK, then long-press your home screen → Widgets → Daily Sunshine.
  • Mac / Windows / Chromebook: in Chrome or Edge click the install icon in the address bar.

Every device shows the same message each day.
